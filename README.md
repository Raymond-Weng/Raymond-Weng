## 👋 嗨，我是 Raymond

我是**國立臺北大學資訊工程學系**的學生，喜歡寫程式、鑽研新東西，還有解決問題的過程。
也練國術多年——寫程式的邏輯思考和練拳的專注沉穩，意外地互補。

- 🎓 NTPU CSIE（2026 –）｜臺北市立大同高中 DTSH（2023 – 2026）
- 🧩 打競賽程式，也自己出題，題目都放在 [咕咕嘎嘎 OJ](https://oj.gugugaga.net/)
- ☕ 主力語言是 Java 和 C++
- 🎬 會攝影、剪輯；🥋 代表臺北市參加全民運動會國術項目
- ✍️ 在[部落格](https://raymondweng.dev/)寫題解、升學心得和各種踩雷紀錄
